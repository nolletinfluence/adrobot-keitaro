# Приёмка и короткая демонстрация

Источники: [полное ТЗ](https://app.notion.com/p/mnovikov/Adrobot-2b01eb78a7bb80a1b188c3a4a1cad55e), [видео редактора](https://youtu.be/jNloscEWCjA).

## Основные сценарии

| Требование | Проверка |
| --- | --- |
| Создание | Название с тестовым префиксом, ISO-код, оффер, домен/группа/источник; в Keitaro два упорядоченных потока |
| Гео-маршрут | Регулярный поток с country accept и HTTP-редиректом на Google |
| Остальной трафик | Default-поток с оффером; первый поток остаётся непрозрачным для редактора |
| Добавление | Выбор по ID/названию, локальный черновик, сумма 100, удалённый набор пока прежний |
| Отмена | Возвращает baseline; новые черновые привязки удаляются, каталог остаётся |
| Архив | После удаления доля 0; публикация убирает привязку в Keitaro; возврат восстанавливает её |
| Внешнее удаление | Синхронизация сохраняет известный оффер в архиве |
| Закрепление | Зафиксированные 25% сохраняются; свободные доли делят 75 с детерминированным округлением |
| Предпросмотр | Перед публикацией видно добавление, архивирование, возврат и изменение долей/закреплений |
| Перезапуск | Черновики, операции и локальное демо-состояние сохраняются |

## Проверка надёжности

1. Повторить создание с тем же ключом и телом: один remote POST, тот же сохранённый результат.
2. Повторить ключ с другим телом: 409 без удалённой записи.
3. Применить публикацию, затем потерять ответ: операция uncertain, поток защищён; reconcile завершает её только GET-запросами.
4. Завершить remote PUT, затем отказать локальному commit: после рестарта сохранённое намерение позволяет подтвердить pin-снимок.
5. Изменить Keitaro извне: конфликт не перезаписывает удалённое состояние и не теряет локальный черновик.
6. Задержать upstream одной публикации: локальное чтение другой кампании продолжает работать.
7. После известного отказа preflight повторить публикацию: новая безопасная попытка возможна. Неизвестный исход сохраняет прежний ключ/резерв.
8. Частично создать кампанию и потерять ответ: alias и известный ID остаются; автоматического повторного POST нет.
9. Переключить трекер при той же базе: target binding блокирует работу со старыми ID.
10. Обновить базу 0001 с dirty/pinned/archive-данными до 0002: исходные данные сохраняются.

## Сценарий записи до трёх минут

- **0:00–0:30:** готовая демо-кампания, два потока, три оффера; добавить четвёртый — 25/25/25/25.
- **0:30–1:00:** обновить страницу, показать сохранённый черновик и preview; отменить, повторить и опубликовать.
- **1:00–1:30:** убрать оффер, опубликовать, вернуть из архива; закрепить 25%, показать пересчёт остальных.
- **1:30–2:20:** изменить распределение, включить разовую потерю ответа, опубликовать; показать защиту потока и завершить через «Проверить результат».
- **2:20–2:45:** журнал с подтверждённой операцией; открыть форму создания с доменом, группой и источником.

Демо маркировано в интерфейсе. Не показывайте live API-ключ или `.env`.
