# Ответы для формы

## Как использовал AI-агентов

Использовал Codex для разбора ТЗ и видео, изучения Keitaro API, реализации backend и frontend, подготовки тестов и независимого ревью. Разделил работу по зонам ответственности: backend с миграциями отдельно, интерфейс и интеграция отдельно. API проверял на реальном тестовом Keitaro; ключи в репозиторий не добавлял.

## Что бы доделал

Для публичного использования добавил бы авторизацию и роли, журнал действий и фоновую синхронизацию. Для нескольких backend-процессов перенёс бы координацию записей в БД. В тестовой учётке доступен один оффер и запрещено создавать дополнительные, поэтому распределение между несколькими офферами проверил API-тестами. Создание кампании, черновики, отмену, публикацию, конфликт с внешней правкой и возврат из архива проверил на живом Keitaro.

## Проверки перед сдачей

Прошли 16 backend-тестов, 7 frontend-тестов, lint/format, миграции вверх/вниз, сборка и запуск через Compose. Результаты и ограничения проверки: [VERIFICATION.md](VERIFICATION.md).
