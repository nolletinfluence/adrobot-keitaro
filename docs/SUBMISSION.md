## Ссылка на репозиторий

## Как использовал ИИ-агентов

Использовал Codex для разработки, тестов и отдельного ревью. С ним разобрал Keitaro API и добил неприятные случаи: повторные запросы, потерянные ответы и перезапуск после записи. Основной сценарий проверили на живом Keitaro, а для проверки без доступов сделал демо с четырьмя офферами и сбоем по кнопке.

## Что не успел или что бы доделал

Основное ТЗ закрыл. Дальше добавил бы авторизацию, роли и координацию между несколькими backend-процессами — сейчас один worker. Неполное создание после обрыва связи требует ручной проверки в Keitaro: автоматически повторять такой POST рискованно.
